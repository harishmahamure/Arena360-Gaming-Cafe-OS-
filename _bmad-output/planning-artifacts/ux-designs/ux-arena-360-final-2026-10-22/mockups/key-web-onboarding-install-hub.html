pairing-codeAn 8-character single-use code in web-display with tabular figures, grouped 4 + 4, with a “Copy code” secondary button beside it and a 15-minute countdown. It sits in a surface card with a border-strong edge. No QR: the owner types the code into the installer on the counter PC.
wizard-progressDesktop: “Step 3 of 10”, then one 44px row per step. Done steps have an ok check and link back for edits; the current step has a hub-line fill and a 2px ring; later steps are muted; Products, Staff and Printer & payments carry “Can skip”. Below 840px it becomes 10 dots (done = ok fill, current = text fill with a 2px ring, later = border-strong ring) plus “Step 3 of 10 · Install Hub”.
Light themeHub tones map to bg-light, surface-light and line-light. The magenta fill (accent-light) carries white ink, and links and the focus ring use accent-text-light as a single 2px ring. The expired message gets a warning-text-light edge. The Hub installer is a Hub surface, so it stays dark.
