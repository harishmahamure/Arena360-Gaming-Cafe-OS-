---
title: Add a standby PC
summary: Keep a second PC that follows your Hub, so you can take over if the main one fails.
category: setup
reviewed: 2026-10-31
---

A standby PC keeps a live copy of your branch. It is available on Basic and Premium.

1. In the Owner app, ask for a standby code.
2. Install the Hub on the second PC and enter the standby code instead of a pairing code. See [install the Hub on Windows](/help/install-the-hub-on-windows).
3. The standby copies the branch from the main Hub and then follows it live. It keeps its own game catalogue and licence.
4. If the main Hub fails, open the standby and promote it to main with a manager PIN.

Promoting sets the old main aside, so keep the old PC off the network until you have decided what to do with it.
